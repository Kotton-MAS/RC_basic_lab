# 条件を変えて試す

**手元の試行は `scratch/` に出る。`results/` は成果物なので触らない。**

`results/` は指紋が `tests/artifact_manifest.csv` に固定された成果物である。
以前はここが `--out` の既定値だったので、条件を 1 つ振るたびに指紋と食い違い
`make ci` が赤くなった。**試行と成果物が同じ場所を奪い合っていた。**

いまは `results/` へ書くのは `make figures-0N`（`--out` を明示する）だけである。

## まず速く回す

```bash
uv run python main.py --experiment 03 --preset quick
```

`quick` は本体の `config.yaml` に**差分だけ**をかぶせる縮小設定である。
実測（2026-08-31）:

| 実験 | 既定 | `--preset quick` | 倍率 |
|---|---|---|---|
| 01 | 1.2 秒 | 1.1 秒 | — |
| 02 | 130 秒 | 4.4 秒 | 30 倍 |
| 03 | 480 秒 | 22 秒 | 22 倍 |
| 04 | 330 秒 | 4.9 秒 | 67 倍 |
| 05 | 350 秒 | 36 秒 | 10 倍 |

**quick の絶対値は本番と比べない。** 系列長やレプリケート数を削っているので、
容量や有効予測時間の値は本番と別物である。見るのは形（rho とともに伸びる /
偶数次が空く / N に比例する）だけ。

プリセットは `experiments/0N_*/presets/quick.yaml` にあり、**なぜその値まで
削ってよいか**が各ファイルに書いてある。自分用のプリセットを足すときは同じ
ディレクトリに置いて `--preset <名前>` で呼ぶ。

## 値を 1 つ振る

```bash
uv run python main.py --experiment 01 --preset quick \
    --set tasks.mackey_glass.reservoir.n_units=50 \
    --set tasks.mackey_glass.reservoir.leak_rate=0.5
```

- 値は **YAML として解釈する**。`200` は int、`0.3` は float、`tanh` は str、
  `[1, 2]` はリスト
- **指数表記は `1.0e-8` と書く**。YAML 1.1 は `1e-8` を数値と認めない。
  そのまま打つと、書き方を示して落ちる
- 複数指定でき、**左から順に**適用する。同じキーを 2 回書けば右が勝つ
- 適用の順は **本体 YAML → `--preset` → `--set`**

### 間違いは黙って通らない

| 間違い | 何が起きるか |
|---|---|
| `--set tasks.mackey_glass.reservoir.n_unit=50`（葉のタイプミス） | `ConfigError: 未知のキーです: n_unit (既知のキー: activation, bias_scale, ...)` |
| `--set esn_mackey_glas.n_units=50`（親のタイプミス） | `OverrideError: esn_mackey_glas という設定はありません (既知: ...)` |
| `--preset quik`（プリセット名のタイプミス） | `FileNotFoundError: プリセットが見つかりません: .../presets/quik.yaml` |
| `--set split.train_ratio=1e-1`（YAML が数値と認めない指数表記） | `OverrideError: 指数表記は仮数に小数点が要ります。1.0e-1 と書いてください` |

**「設定したのに効いていない」が起きない**ことが、この仕組みの価値である。
上書き専用の検査を別に書かず、既存の読み込み規律（D-09）にそのまま乗せてある
ので、YAML 側と CLI 側で厳しさが割れることもない。

## 何を振ったか後から辿る

`--set` の結果は `meta.json` の `config` に**効いた値として**入る。
コマンドを覚えていなくても、`scratch/0N_*/meta.json` を見れば何で回したか分かる。

## 成果物を作り直す

```bash
make figures-03      # results/03_capacity/ を再生成する
```

**`--preset` や `--set` は付けない。** 成果物は本体の `config.yaml` だけから
作る。付けて再生成すると指紋が変わり、`make ci` が赤くなる（それが正しい）。
