# リザバーの主張に対照を置く

**「X が効く」と書く前に、X 以外が動いていないことを測る。**

この文書は「何を測るか」ではなく「**何と比べるか**」の手順です。汎用基盤側の
文書なので連載を知りません (D-126)。実験を足す手順は
`docs/guide/実験を足す.md` にあります。

---

## 結論を先に

リザバーに関する「X が効く」という主張には、次の3つのうち**該当するものを
隣に置きます**。

| # | 対照 | 何を殺すか | このリポジトリでの実装 |
|---|---|---|---|
| 1 | **次数保存ランダム化** | 「構造が効いた」が実は次数分布だった | `DegreePreservingConfig` (D-135) |
| 2 | **シャッフル代替 (サロゲート)** | 「容量が立った」が実は有限標本の偽陽性だった | `threshold_mode="surrogate"` (D-27) |
| 3 | **探索予算をそろえた素朴な対照** | 「手法が強い」が実は探索予算の差だった | 同一 alpha 格子 / 同一分割 (D-04 / D-05 / D-08) |

3つとも「対照が無いと通ってしまう主張」を1つずつ潰します。**どれも
`results/` の CSV に列として出ます**。図や本文の数字は、その列から導きます。

---

## 1. 構造の主張には次数保存ランダム化を置く

### いつ要るか

「トポロジ A のほうが良い」と言うとき。

### なぜ

同じ密度で Erdős–Rényi と Barabási–Albert を比べると、**同時に4つ動きます**
(D-131 / D-140):

| # | 交絡 | 実測での動き方 |
|---|---|---|
| 1 | 次数分布 (ハブの有無) | BA の最大入次数 17.2 に対し ER は 8.4 |
| 2 | 相互結合率 | BA は辺が対称、ER は独立 |
| 3 | 自己ループ | ER は持つ、BA は持たない |
| 4 | ρ 正規化との相互作用 | 同じ ρ でもノードごとの実効ゲインの分布が違う |

**「BA が良かった」はこの4つのどれの話か分かりません。**

### 手順

**交絡を1つだけ動かした水準を並べます**。

| 水準 | 何が基準から動いているか |
|---|---|
| ER | (基準) |
| ER を対称化 | 相互結合だけ |
| ER の対角を 0 に | 自己ループだけ |
| **BA を次数保存ランダム化** | **次数分布だけ** |
| BA | 全部 |

4段目が本命です。BA のグラフを取り、**次数列を保ったまま辺を張り替えます**
(double edge swap)。ハブの次数分布は保たれ、優先的選択が作った相関構造だけが
壊れます。

- ここで BA の差が**残る** → 効いているのは次数分布
- **消える** → 効いていたのは生成過程が作る別の何か

### 落とし穴 (実測で踏んだもの)

- **密度は「設定した値」ではなく「生成された行列」でそろえる** (D-140)。
  `mask | mask.T` は密度を `d` から `2d − d²` に上げます。設定値だけを見て
  いた間、対称化した対照は実測でほぼ倍の辺を持っていました
- **BA の密度 `2m/N` は近似です**。初期の完全結合を数え落とすので、
  N=25 / m=2 で 6% ずれます。厳密には `m(m+1) + 2m(N−m−1)`
- **同じ重み行列を水準ごとに違うマスクで切り出す** (D-134)。別々に引くと
  水準差に重みの実現値の分散が混ざります
- **グラフと重みを入れ子にする**。実測でグラフ間 s.d. 0.69〜0.83 に対し
  重み間 s.d. 0.71〜0.94 と同程度でした。片方だけを振ると、差がもう一方の
  分散に埋もれているかを判定できません
- **`spectral_gap` で交絡4 は測れません**。実行列の固有値は共役対で出るので
  `|λ₁| − |λ₂|` は構造的に 0 です。代わりに行の L2 ノルム (`effective_gain`)
  を使います

## 2. 容量の主張にはシャッフル代替を置く

### いつ要るか

「容量が N ビットある」「非線形容量が立っている」と言うとき。

### なぜ

有限標本では、**関係が無い目標にも容量が立ちます**。完全な遅延線 (線形しか
持たない系) で非線形容量を測ると、T=4,000 で 0.338 出ます。これは全部偽陽性
です。

### 手順

入力系列をシャッフルして同じ回帰を回し、その分布の上側分位点をしきい値に
します。しきい値を超えた成分だけを足します。

### 落とし穴

- **しきい値の設定が結論を作っていないことを別に測る**。本数と分位点を振って
  順位が動かないことまで見ます (実測: 本数 25〜400、分位点 0.95〜0.999、
  さらに**しきい値なし**まで含めて、水準間の差の幅は効果の 1〜2%)
- **偽陽性の下駄は T とともに縮みます** (T=4,000 で 0.338 → T=16,000 で
  0.045)。縮まないなら有限標本ではなく系統誤差です
- **解析解で絶対値を当てておく**。上限 (`≤ N`) と単調性だけの検査は、容量が
  体系的に何割か目減りしていても通ります (実測: `mc_total` を 0.95 倍に潰す
  変異が既存の検査を全て素通りした)。完全遅延線なら `mc_total` は厳密に段数、
  `P2(u[t−1])` 1列なら容量は全部次数2に乗ります

## 3. 手法の主張には探索予算をそろえた素朴な対照を置く

### いつ要るか

「リザバーのほうが強い」「この手法が最良」と言うとき。

### なぜ

対照が正則化なしの最小二乗だったり、ハイパーパラメータ探索の予算が違ったり
すると、比べているのは手法ではなく**探索予算**です。

### 手順

- **同一の正則化パラメータ格子**を全手法が読む
- **同一の分割**を使い、係数を作れる場所を1つに閉じる
- **構造ハイパーパラメータを検証分割で選ばない**。宣言した1点をそのまま報告

### 落とし穴

- **その1点で勝敗が決まっていないかを測る**。実測では、同じ課題・同じ探索
  予算でも、リザバー側の動作点 (N・リーク率) を振ると 12 点のうち 2 点で
  勝敗が反転しました。1点だけを報告すると、**動作点を1つ選んだ結果**を現象
  として報告することになります
- **対照が動作点で動いていないことを検査に置く**。リザバーを見ない手法
  (線形回帰・遅延線) の成績は動作点によらず一定のはずで、動いたなら課題か
  分割まで一緒に動いています

## 主張を書く前のチェックリスト

- [ ] 主張が構造についてなら、次数保存ランダム化との差を出したか
- [ ] 主張が容量についてなら、しきい値を振っても順位が動かないことを見たか
- [ ] 主張が手法についてなら、探索予算をそろえ、動作点を振ったか
- [ ] 対照が「動いてはいけない側」であることを、**テストで**固定したか
- [ ] 数字は `results/` の列から導いたか (図の見出しを固定文にしていないか)
- [ ] 密度・次数などの「そろえた」量を、**設定値ではなく実測**で確かめたか

最後の項目が一番踏みます。このリポジトリでは
「そろえたつもり」が**実測と食い違っていた事例が2件**あり、どちらも設定値
どうしを比べる検査しか無かったために気づけませんでした。
