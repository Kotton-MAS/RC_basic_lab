# 型と名前の対応表

抽象的な名前から**実体**へ引くための表。`FeatureSpec` や `StateUpdater` の
ような名前は、定義を開くまで何なのか分からない。ここで一段目を引く。

**新しい抽象を足したらここに 1 行足す。** `tests/test_type_glossary.md` が
「公開 Protocol と型エイリアスが全部載っているか」を見るので、忘れると
`make ci` が赤くなる。

## 型エイリアス

| 名前 | 実体 | どこで使うか |
|---|---|---|
| `FloatArray` | `np.ndarray[float64]` | 数値配列すべて。形は各 API の docstring に書く |
| `BoolArray` | `np.ndarray[bool_]` | 異常ラベル・マスク・予測。**定義は `types.py` の 1 箇所** |
| `FeatureSpec` | `PassthroughSpec \| DelayLineSpec \| ReservoirSpec` | **3 ベースラインを分ける唯一の軸**。分岐は `readout/design.py` の `_layout_of` だけ |
| `ReservoirConfig` | `ESNConfig \| DeepESNConfig \| RingConfig` | リザバーの構造設定。分岐は `reservoir/registry.py` の `build_reservoir` だけ |
| `TopologyConfig` | `ErdosRenyiConfig \| RingTopologyConfig \| BarabasiAlbertConfig \| WattsStrogatzConfig` | **結合構造。モデルと独立の軸**。分岐は `reservoir/topology.py` の `build_mask` だけ |
| `TargetSpec` | IPC の目標信号 1 本の仕様（次数と遅延の組） | `diagnostics/ipc.py` |
| `ScoreSpec` | 異常スコア 1 系統の作り方 | `experiment/anomaly_score.py`。**6 系統を分ける唯一の場所** |
| `Opener` | URL を開く呼び出し可能オブジェクト | `datasets/fetch.py`。テストで差し替えるための注入点 |

## Protocol（満たすべき面）

| 名前 | 何を要求するか | 実装 |
|---|---|---|
| `Reservoir` | `run` / `step` / `config` / `n_units` / `n_inputs` | `ESN`。足し方は `docs/リザバーを足す.md` |
| `Diagnostic` | 状態行列 `X` から計量を返す | `diagnostics/` の各モジュール |
| `StatePropagator` | `X[t]` から `X[t+1]` を返す（**決定的**） | 02 の ESP / Lyapunov |
| `StateUpdater` | 状態と入力から次状態（自走の閉ループ用） | 04。`esn_state_updater` などのアダプタ |
| `TaskGenerator` | 乱数生成器から課題データを作る | `tasks/` の各課題 |
| `SeriesSource` | 名前から異常検知用の系列を返す | MGAB / UCR / 合成 |
| `HttpResponse` | `read` / ステータス | `datasets/fetch.py` のテスト用 |
| `HasReplicate` | `replicate` 属性を持つ行 | 図の footnote がレプリケート数を数える |

## 紛らわしい対

| 対 | 違い |
|---|---|
| `run` と `step` | `run` は系列全体 `(T, D) -> (T, N)`、`step` は 1 ステップ。**自走は `step` を使う**（`run` を使うと教師強制になる） |
| `StatePropagator` と `StateUpdater` | 前者は 02 用で**決定的**（診断が再現しないと困る）、後者は 04 用で `state_noise > 0` なら rng を取る（D-48 / D-36） |
| `nrmse` と `nmse` | `nmse == nrmse²`。文献の土俵に合わせて使い分ける（FIG-4） |
| `mc_total` と `mc_total_raw` | `raw` はしきい値処理の前。図と結論は `mc_total` を使う |
| `t0` と `washout` | `washout` は設定値、`t0` は `max(全手法の first_valid, washout)` の実際の開始行。**全手法が同じ `t0` を使う**（D-05） |

## 日本語と英語の使い分け

- **コードの識別子は英語。** 例外なし
- **docstring とコメントは日本語。** 読者（連載の書き手）が日本語で考えるため
- **図のラベルは ja/en の対で書く**（D-10）。`style.label(ja, en)` を通す
- **ソースにギリシャ文字を書かない**（RUF001/RUF002）。`rho` / `sigma_u` と綴る
