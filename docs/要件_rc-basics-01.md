# 要件: rc-basics-01 実験実装 —— リザバー計算とは何か

*記事: `rc-basics-01`「リザバー計算とは何か — なぜ読み出しだけ学習するのか」*
*本書は `rc-basics-lab` リポジトリの初期構築を兼ねる*

---

## 目的

記事01の小実験「リザバーは何を足しているのか」を実行可能にする。
あわせて、基礎編3本を通じて使うリポジトリ基盤(リザバー・タスク・ベースライン・評価・作図)を構築する。

**重要な設計目標**: ここで書く診断・評価コードは、後続の `memristor-rc-lab`(メモリスタネットワーク)に
**そのまま移植できる**こと。そのためリザバー実装と診断・評価を疎結合にする(下記「設計判断1」)。

## スコープ

### やること
- リポジトリ基盤(下記「共通基盤」)
- ESNコア: `W_in`・`W`・リーク率・washout・リッジ読み出し(閉形式)
- ベースライン3種: 線形回帰(`[1, u]`)、遅延線(`[1, u[t..t-k]]`)、ESN(`[1, u, x]`)
- タスク2種: Mackey-Glass 1ステップ先予測 / 遅延パリティ(記憶+非線形性を要求)
- 実験1-A: 3ベースラインの性能比較(同一タスク・同一分割・シード固定)
- 実験1-B: リザバー状態のPCA可視化(入力空間 vs 状態空間の広がり)
- 図の生成スクリプト(記事に貼るPNG)

### やらないこと
- ESP・MC・IPCの診断(記事02・03で実装。ただしインターフェースは先に切る)
- スパイキングニューロン/LSMの実装(記事本文では概念紹介のみ)
- ハイパーパラメータの網羅探索(各手法とも最小限の探索に留め、探索予算を揃えることを優先)
- GPU利用(全実験CPUで完結する規模)

## 設計判断

1. **診断・評価は「状態行列を受け取る純関数」として書く**
   `f(X, u, y)` の形(`X`: shape=(T, N) の状態系列、`u`: 入力、`y`: 目標)。
   ESNのクラスに紐づけない。これにより記事02・03の診断コードが、
   メモリスタネットワークの状態系列にもそのまま適用できる
2. **設計行列の構成を1箇所に集約**: `[1, u]` / `[1, u, lags] / [1, u, x]` を同一APIで切り替え可能にする。
   ベースライン比較が実装差ではなく設計行列の差のみになるようにする
3. **探索予算を揃える**: 手法間比較では ridge_alpha の探索格子を全手法で共通にする
   (esn-vla-uq §11の教訓: alphaを固定すると逆の結論が出うる。条件ごとに最良化し、格子は揃える)
4. **乱数**: リザバー生成・タスク生成・分割のシードを分離して管理。全実験で固定

## 入力 / 出力

- **入力**: 実験設定YAML(タスク種別・パラメータ / リザバー設定 / ベースライン一覧 / alpha格子 / シード)
- **出力**:
  - `results/comparison.csv`: 手法×タスクの誤差(NRMSE)と、シード複数本の平均±標準偏差
  - `results/fig_comparison.png`: 3ベースラインの性能比較(棒グラフまたは点+誤差棒)
  - `results/fig_state_space.png`: 入力空間とリザバー状態空間のPCA可視化
  - `results/meta.json`: 設定・シード・コミットハッシュ

## 受け入れ条件

1. 3ベースライン(線形・遅延線・ESN)が**同一API**で切り替えられ、同一分割・同一alpha格子で比較できる
2. 遅延パリティタスクで、線形回帰が解けずESNが解けることを数値で示せる(リザバーの価値の実演)
3. Mackey-Glass予測で3手法の誤差が出力され、シード5本以上の平均±標準偏差が付く
4. リザバー状態のPCA可視化が、入力空間より高次元に広がっている様子を示せる
5. 図2枚が1コマンドで再生成でき、記事に貼れる解像度(retina対応)で出る
6. 診断層のインターフェース(`f(X, u, y)`)が定義され、ダミー実装+テストがある
7. pytest green + 最小CI + README(3コマンドで実験再現)

## 決定済み事項(2026-08-16サーベイ反映)

- **LSMの現状の記述方針**(旧未確定5): 解決。「SNN研究に吸収されつつある」は**不正確なので使わない**。
  LSMはニューロモルフィック分野で現役(SpiNNaker等への実装でN-MNISTの最先端性能報告、
  リザバー分離度最適化・ニューロン単位パラメータの神経進化・LSM+SOMの教師なし化など2024–26に継続)。
  記事での正しい整理は「**ESNは機械学習・物理RCの文脈で、LSMはニューロモルフィックハードウェアの文脈で、
  別々のコミュニティで生き続けている**」。起源の違い(工学 vs 神経科学)が現在の応用先の違いに対応している、
  という書き方にする。2026年のレビューがESN/LSMを連続値 vs スパイキングの2系統として並置している
