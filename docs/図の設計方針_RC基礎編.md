# 図の設計方針【RC基礎編・連載通し】

*作成: 2026-08-20 / 対象: `rc-basics-01` 〜 `05` のすべての図*
*関連: `docs/連載構成案_RC基礎編.md`（各記事の図の枚数目安）、`docs/rc-basics-survey.md`（引用すべき先行研究と定量参照点）*

---

## 目的

各記事の図が単体で流通しても、次の3つが**図の中だけで読める**ようにする。

1. 何を主張しているか
2. 先行研究のどこに位置するか
3. どの条件で測ったか

実装側（参照線の値・文献値との照合・原典未特定の明記）は既に整っている。足りているのに読者の目に届いていない、というのが現状の診断である。

### 現状で既にできていること（変えない）

- 参照線が4種類引かれている: NARMA10 の NMSE = 0.16 / 0.107、MC ≤ N、IPC_total ≤ N、Lorenz の λ_max = 0.9056
- `plotting/figures_capacity.py::_reference_lines` が、参照線のラベルが欠けたら**描画前に落とす**
- `diagnostics/lyapunov.py` が「文献値は照合専用、正本は数値推定」を設計で分離している（D-42）
- 原典未特定であることを図の注に明記している（`NARMA10_REFERENCE_NOTE`）

---

## FIG-1: 図タイトルは結論文で書く

タイトルは「何を描いたか」ではなく**「何が言えたか」**を書く。説明はサブタイトルか軸ラベルに逃がす。

- 良い例（現状の 2-C）: `実験 2-C: 入力を強くすると rho > 1 でも ESP は成立する`
- 直す例（現状の 3-B）: `実験 3-B: rho とリーク率で動く線形/非線形の配分`
  → `実験 3-B: rho を上げると非線形容量の割合は下がる`

先行研究の再実演・追試である図は、**サブタイトルに `著者 (年) の再実演` / `著者 (年) の対照を公平化した再実験` を必ず入れる**。2-C（`figures_esp.py` の副題）が既にこの形になっている。

---

## FIG-2: 各記事に「文献照合」を最低1枚置く

記事ごとに、自分の実測値と文献値を**同じ軸の上に置いた図**（または対照表）を1枚必ず用意する。列は固定する。

| 量 | 本実験値 | 文献値 | 出典 | 条件差（N・入力・指標・正則化） |
|---|---|---|---|---|

- 図にする場合は、文献値を破線・実測を点＋誤差棒で重ねる
- 「文献値が無い」も情報である。空欄ではなく**「文献値なし」と明示する**
- 引用元は `docs/rc-basics-survey.md` に既に整理されている。survey に書いてある定量参照点が図に落ちていない状態を無くす

---

## FIG-3: 参照線には出典を図の中に書く

凡例テキストに `著者 (年)` を含める。本文の注は切り取られると消えるので、注だけに置かない。

| 現状 | 変更後 |
|---|---|
| `上限 MC <= N = 200` | `上限 MC ≤ N (Jaeger 2002 / Dambre 2012)` |
| `上限 IPC_total = N (傾き1)` | `上限 IPC_total ≤ N (Dambre 2012)` |
| `参照 NMSE = 0.16 (非線形性なしの天井)` | 末尾に `[原典未特定]` を付す（図の注は残す） |

`plotting/labels.py::label` は ja / en の両方を必須にしているので、追加する凡例は英語版も同時に書く。

---

## FIG-4: 指標と正規化を文献の土俵に合わせる

**指標の混在を解消する。** 現状 NMSE（3-C）/ NRMSE（4-B）/ RNMSE（文献側）が混在している。文献と比較する図では軸ラベルに定義式を書くか、図の注に `NMSE = ...` を置く。

`figures_capacity.py` の「参照値が NMSE で流通しているから誤差指標を NMSE にする」という判断が**正解の型**である。同じ判断基準を他の図にも適用する。

**上限が遠いときは正規化軸にする。** 3-A 左パネルは対数軸で上限 200 と実測 10〜40 が離れすぎ、「上限からどれだけ遠いか」という肝心の情報が読めない。`MC / N` を第2軸に置くか、主軸を `MC / N` に変える。

---

## FIG-5: 色の意味を連載通しで固定する

手法・条件と色の対応を `plotting/style.py` に定数で持ち、5記事すべてで同じ色を使う。読者は記事をまたいで同じ対照群を見る。

- **手法（カテゴリ）**: 線形 / 遅延線（リッジ） / 遅延線（OLS・先行再現） / ESN — 固定4色
- **連続量（rho・リーク率・N のスイープ）**: viridis 系で統一
- **参照線・理論上限**: 常に同一色＋破線。データ系列と絶対に同色にしない

現状は 3-A（viridis）/ 3-B（tab:blue, tab:orange）/ 3-B'（独自）/ 3-C・4-B（単色）でバラバラ。

---

## FIG-6: 図に再現条件を焼き込む

`meta.json` にある情報が、図単体になった時点で失われている。図の隅（footnote 位置）に小さく1行入れる。

```
N=50, sigma_u=0.2, seeds=0-9 (10 rep), commit=abc1234
```

タイトルに `(N = 200, sigma_u = 0.1)` を入れている図が既にあるので、**それを全図共通の footnote に移して機械生成する**。手書きにすると図ごとに揃わない。

---

## FIG-7: 打ち切り・欠測を「データ」に見せない

`fig_ipc_profile.png`（3-B）は面積の約7割が 0 で、見えている矩形ブロックは打ち切り設定 `{(1,60),(3,10),...}` の形そのものである。読者はこれを系のデータ構造と誤読する。

- 打ち切り境界を白線か枠で明示し、境界外は「未計算」として 0 とは別の色（グレー）にする
- 遅延軸を対数にして、低遅延側の情報密度を上げる
- Dambre 2012 の定番は次数別の積み上げなので、3-B のスタックバーを主図、heatmap を補図に格下げすることも検討する

### 3-C を最優先にする理由

`docs/rc-basics-survey.md` は実験 3-C の位置づけを、

- 旧: 「NARMA10 は線形で解けるのでは?」
- 新: 「**先行 (Goudarzi et al. 2014) の対照は正則化なし OLS だった。公平な対照で再実験する**」

に方向転換している。ところが現在の `fig_narma10_control.png` には Goudarzi の数字も、正則化なしの条件も出ていない。図が伝えているのは「遅延線 0.1538 < ESN 0.2673」だけで、**記事の主張が視覚的に成立していない**。同一図に OLS 版を並べて初めて「正則化を入れると結論が変わる」が図で言える。

## 実装上の置き場所

- 色・footnote 生成・参照線の描画は `plotting/style.py` と共通ヘルパに集約する。各 `figures_*.py` に散らすと FIG-5 が静かに崩れる
- `figures_capacity.py::_reference_lines` の「ラベルが欠けたら描画前に落とす」仕組みは正しいので、**出典文字列も同じ検証対象に含める**。値だけ足して出典を書き忘れる事故を落とす
- FIG-4 の指標選択（なぜ NMSE を採るか）は「普通はこうするが今回は理由があって別の選択をする」判断にあたるため、`.claude/decisions.yaml` に guard_test 付きで記録する
