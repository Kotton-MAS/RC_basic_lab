# 図の設計方針【RC基礎編・連載通し】

*作成: 2026-08-20 / 対象: `rc-basics-01` 〜 `05` のすべての図*
*関連: `docs/連載構成案_RC基礎編.md`（各記事の図の枚数目安）、`docs/rc-basics-survey.md`（引用すべき先行研究と定量参照点）*

---

## 目的

各記事の図が単体で流通しても、次の3つが**図の中だけで読める**ようにする。

1. 何を主張しているか
2. 先行研究のどこに位置するか
3. どの条件で測ったか

実装側（参照線の値・文献値との照合・原典未特定の明記）は既に整っている。足りているのに読者の目に届いていない、というのが現状の診断である。

### 現状で既にできていること（変えない）

- 参照線が4種類引かれている: NARMA10 の NMSE = 0.16 / 0.107、MC ≤ N、IPC_total ≤ N、Lorenz の λ_max = 0.9056
- `plotting/figures_capacity.py::_reference_lines` が、参照線のラベルが欠けたら**描画前に落とす**
- `diagnostics/lyapunov.py` が「文献値は照合専用、正本は数値推定」を設計で分離している（D-42）
- 原典未特定であることを図の注に明記している（`NARMA10_REFERENCE_NOTE`）

## FIG-1: 図タイトルは結論文で書く

タイトルは「何を描いたか」ではなく**「何が言えたか」**を書く。説明はサブタイトルか軸ラベルに逃がす。

- 良い例（現状の 2-C）: `実験 2-C: 入力を強くすると rho > 1 でも ESP は成立する`
- 直す例（現状の 3-B）: `実験 3-B: rho とリーク率で動く線形/非線形の配分`
  → `実験 3-B: rho を上げると非線形容量の割合は下がる`

先行研究の再実演・追試である図は、**サブタイトルに `著者 (年) の再実演` / `著者 (年) の対照を公平化した再実験` を必ず入れる**。2-C（`figures_esp.py` の副題）が既にこの形になっている。

---

## FIG-2: 各記事に「文献照合」を最低1枚置く

記事ごとに、自分の実測値と文献値を**同じ軸の上に置いた図**（または対照表）を1枚必ず用意する。列は固定する。

| 量 | 本実験値 | 文献値 | 出典 | 条件差（N・入力・指標・正則化） |
|---|---|---|---|---|

- 図にする場合は、文献値を破線・実測を点＋誤差棒で重ねる
- 「文献値が無い」も情報である。空欄ではなく**「文献値なし」と明示する**
- 引用元は `docs/rc-basics-survey.md` に既に整理されている。survey に書いてある定量参照点が図に落ちていない状態を無くす

---

## FIG-3: 参照線には出典を図の中に書く

凡例テキストに `著者 (年)` を含める。本文の注は切り取られると消えるので、注だけに置かない。

| 現状 | 変更後 |
|---|---|
| `上限 MC <= N = 200` | `上限 MC ≤ N (Jaeger 2002 / Dambre 2012)` |
| `上限 IPC_total = N (傾き1)` | `上限 IPC_total ≤ N (Dambre 2012)` |
| `参照 NMSE = 0.16 (非線形性なしの天井)` | 末尾に `[原典未特定]` を付す（図の注は残す） |

`plotting/labels.py::label` は ja / en の両方を必須にしているので、追加する凡例は英語版も同時に書く。

---

## FIG-4: 指標と正規化を文献の土俵に合わせる

**指標の混在を解消する。** 現状 NMSE（3-C）/ NRMSE（4-B）/ RNMSE（文献側）が混在している。文献と比較する図では軸ラベルに定義式を書くか、図の注に `NMSE = ...` を置く。

`figures_capacity.py` の「参照値が NMSE で流通しているから誤差指標を NMSE にする」という判断が**正解の型**である。同じ判断基準を他の図にも適用する。

**上限が遠いときは正規化軸にする。** 3-A 左パネルは対数軸で上限 200 と実測 10〜40 が離れすぎ、「上限からどれだけ遠いか」という肝心の情報が読めない。`MC / N` を第2軸に置くか、主軸を `MC / N` に変える。

---

## FIG-5: 色の意味を連載通しで固定する

手法・条件と色の対応を `plotting/style.py` に定数で持ち、5記事すべてで同じ色を使う。読者は記事をまたいで同じ対照群を見る。

- **手法（カテゴリ）**: 線形 / 遅延線（リッジ） / 遅延線（OLS・先行再現） / ESN — 固定4色
- **連続量（rho・リーク率・N のスイープ）**: viridis 系で統一
- **参照線・理論上限**: 常に同一色＋破線。データ系列と絶対に同色にしない

現状は 3-A（viridis）/ 3-B（tab:blue, tab:orange）/ 3-B'（独自）/ 3-C・4-B（単色）でバラバラ。

## FIG-6: 図に再現条件を焼き込む

`meta.json` にある情報が、図単体になった時点で失われている。図の隅（footnote 位置）に小さく1行入れる。

```
N=50, sigma_u=0.2, seeds=0-9 (10 rep), commit=abc1234
```

タイトルに `(N = 200, sigma_u = 0.1)` を入れている図が既にあるので、**それを全図共通の footnote に移して機械生成する**。手書きにすると図ごとに揃わない。

## FIG-7: 打ち切り・欠測を「データ」に見せない

`fig_ipc_profile.png`（3-B）は面積の約7割が 0 で、見えている矩形ブロックは打ち切り設定 `{(1,60),(3,10),...}` の形そのものである。読者はこれを系のデータ構造と誤読する。

- 打ち切り境界を白線か枠で明示し、境界外は「未計算」として 0 とは別の色（グレー）にする
- 遅延軸を対数にして、低遅延側の情報密度を上げる
- Dambre 2012 の定番は次数別の積み上げなので、3-B のスタックバーを主図、heatmap を補図に格下げすることも検討する

### 仕様の外で決めたこと

1. **出典の書式は `本文 [著者 年]`**（角括弧）。丸括弧は既存のラベルが単位や条件に使っており（`(傾き1)` / `(a = 1.0)`）、混ざると出典が読み取れないため。
2. **出典を要求するのは文献由来の参照線だけ**とした。定義から出る線（2-A の丸めの床、2-B の `1/e` と `-1/log(1-a)`、01 の `NRMSE = 1`）は体裁（黒・破線）だけ揃え、出典は付けない。「定義」という出典を書くと `[原典未特定]` の重みが下がる。
3. **footnote に載せるのはレプリケート番号であってシード値ではない。** 行の `seed_*` 列は基底シードで、全レプリケートで同じ値である（実測: `capacity.csv` 117 行すべて `seed_reservoir=0`）。仕様の例 `seeds=0-9 (10 rep)` は `3 rep (replicate 0-2)` の形に読み替えた。
4. **footnote に commit を焼き込むと、PNG は生成時の HEAD に依存する。** D-74 の「再生成してバイト一致するか」で図の退行を判定する運用は、これで PNG にも効かなくなる（CSV の `wall_time_s`・`meta.json` の `timestamp_utc` は元から同じ性質で、PNG が最後のバイト安定な成果物だった）。**それでも焼き込む**という判断の理由は D-87 の rationale にある。
5. **参照線の色は黒に固定した。** 手法4色・05 の系統6色・04 の3態色・`SOURCE_STYLE` のいずれとも重ならない唯一の無彩色だったため。2本以上並ぶときは色ではなく破線の刻みで区別する。
6. **`delay_line_ols` は色だけ先に確保した。** 実験として足すのは今回の範囲外だが、後から色を挿すと既存4記事の配色がずれる。
7. **01 の PCA 図の空間色を、対応する手法の色に合わせた**（`入力の遅延埋め込み` = 遅延線の青、`リザバー状態` = ESN の緑）。記事をまたいで「どの特徴量の話か」が色で読める。
8. **FIG-4 は主軸ではなく第2軸にした。** 主軸を `MC / N` にすると上限線 `y = N` が `y = 1` になって「上限」という語と数字が結びつかない。第2軸なら実測値と割合の両方が読める。**N が1つに定まるときだけ引く**（格子に複数の N が混ざると `MC / N` が一意でない）。
9. **打ち切り（FIG-7）は設定から作図関数の引数として渡す。** 長形式（D-38）には正値セルしか無く、「未計算」と「しきい値を超えなかった 0」は行から区別できない。CSV に列を足すと成果物が変わるので採らなかった。引数を省略したときはマスクしない（打ち切りを知らない呼び出し側が「測っていない領域」を捏造しないため）。
10. **3-B のスタックバーを主図に格下げ・格上げする案は採らなかった**（FIG-7 の「検討する」）。図の入れ替えは記事構成の判断であって、実装者が決めることではない。

## FIG-8: 図が主張することは、その図の条件で検証されていること

FIG-1（タイトルは結論文で書く）を入れた結果、**根拠より先に主張が出る**という新しい失敗が生まれた。
結論文にする以上、**その結論がその図の条件で本当に検証されているか**を書く前に確かめる。

### 実例1: 3-C が Goudarzi の対照を再現していない

`fig_narma10_control.png` の副題は「Goudarzi et al. 2014 の対照 (正則化なし) を第4水準に足した」だが、
実測すると**この設定では過学習が起こりえない**。

| | 本実験 | Goudarzi et al. 2014 |
|---|---|---|
| タップ数 | 最大 30（`config.yaml:142` `n_lags_grid: [10,15,20,25,30]`） | 1,810〜2,000 |
| 訓練長 | 3,800 | 2,000 |
| **タップ数 / 訓練長** | **≒ 0.008** | **≒ 1** |

先行の対照の本質は「正則化なし」ではなく「**正則化なし かつ k ≈ n_train**」である。
公平化されたのは正則化の軸だけで、**タップ数の軸が動いていない**。
「OLS ≒ リッジ（0.1534 vs 0.1538）」は実測として正しいが、**先行の対照設計への批判を検証していない**。

**対応（どちらかを選ぶ。現状の副題のまま残さない）**

- **(a) 記事の芯を成立させる**: `n_lags` を k / n_train が 1 に近づくところまで掃引し、
  OLS が壊れてリッジが壊れない点（あるいは両方壊れる点）を示す。
  `docs/rc-basics-survey.md` 未解決3「Goudarzi の DL をリッジ化した追試は誰かやっているか」と接続する
- **(b) 射程を限定する**: 副題と注から「Goudarzi の対照」の主張を外し、
  「小さいタップ数では正則化の有無が結論を変えない」という限定された主張に書き換える

### 実例2: 4-B が参照線なしで「数 Lyapunov 時間」と主張している

`fig_valid_time.png` のタイトルは「自走が真の軌道からずれるまでの時間は**数 Lyapunov 時間**」になったが、
**図の中に文献の有効予測時間の参照線が無い**。4.83 が妥当な水準だという根拠が図に無いまま、
タイトルだけが判断を済ませている。**参照線が無かった初版時点より、主張が先行している分むしろ危うい。**

FIG-2（各記事に文献照合を最低1枚）は 4-B に限らずどの実験でも未実装であり、
`tests/test_figure_policy.py` にも対応する検査が無い。
**FIG-1 / 3 / 4 / 5 / 6 / 7 が機械化された一方で、FIG-2 だけが方針から落ちている。**

## FIG-9: 図に見える目立った構造は、主張していなくても1行で説明する

`fig_ipc_profile.png`（3-B）は次数1と3に容量があり、**次数2と4は全パネルで真っ暗**である。
入力が対称（一様・平均0）で tanh が奇関数であるため偶数次の容量が消える、という説明が付くはずだが、
図にも注にも無い。

タイトル「rho を上げると次数3の容量が失われ、残るのは次数1になる」は正しい。
しかし読者が最初に目を引かれるのは「**なぜ 2 と 4 だけ空なのか**」であり、そこに答えが無いと
タイトルの主張まで疑われる。

FIG-7 で「未計算」をグレーにして 0 と区別できるようにした以上、**「0 である理由」も 1 行あるべき**である。

**規約**: 図の面積の相当部分を占める構造（空の帯・全面ゼロの行や列・不連続な段差）は、
その図の主張に含まれていなくても注で 1 行説明する。説明できないなら、それは調べるべきことである。
