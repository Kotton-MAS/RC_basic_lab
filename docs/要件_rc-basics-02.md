# 要件: rc-basics-02 実験実装 —— ESN を動かして測る

*記事: `rc-basics-02`「ESNを動かして測る — ESP・スペクトル半径・リーク率」*
*前提: `rc-basics-01` の基盤が構築済み*

---

## 目的

記事02の小実験を実行可能にする。中心は **Echo State Property(ESP)の可視化と、
「スペクトル半径 < 1」という通説の検証**。

**移植目標**: ここで実装するESP判定は `memristor-rc-lab` の連載#2(不揮発素子でESPは成立するか)の
中核部品になる。リザバー実装に依存しない純関数として書くこと(01の設計判断1に準拠)。

## スコープ

### やること
- **ESP判定モジュール**(`diagnostics/esp.py`):
  - 2つの異なる初期状態から同一入力を流し、状態距離 `||x_a[t] − x_b[t]||` の時間発展を返す
  - 収束判定(閾値・判定窓は設定可能)
  - 条件付きLyapunov指数の数値推定(摂動法。**#3およびメモリスタ連載#3で再利用**)
- 実験2-A: **ESPを目で見る** —— ρを変えた複数条件で状態距離の減衰曲線を重ね描き
- 実験2-B: **リーク率は何を変えるのか** —— リーク率掃引に対する状態の自己相関減衰(実効時定数)の可視化
- 実験2-C(課題パートの実証): **入力駆動下では ρ>1 でもESPが成立しうる**ことの数値実演
  - 無入力・弱入力・強入力の3条件 × ρ格子でESP成立領域をヒートマップ化
  - **⚠️ 先行あり**: Gallicchio "Chasing the Echo State Property" が経験的ESP indexを導入して
    入力駆動下の安定領域を解析し「ESPの実際の妥当領域は文献条件よりずっと広い」と報告済み。
    本実験は**新規発見ではなく再実演**として位置づけ、記事で明示的に引用すること
- 実験2-D(課題パートの実証): **washout長への感度** —— washoutを変えて予測性能がどれだけ動くか

### やらないこと
- MC・IPCの測定(記事03)
- edge of chaos の性能相関(記事本文では論争の紹介に留め、検証は本編連載#3)
- ESP理論条件の解析的導出(記事は実測の可視化に徹する)

## 設計判断

1. **ESP判定は `f(state_sequence_a, state_sequence_b) -> ESPResult` の純関数**。
   リザバーの生成方法(ESN / メモリスタ回路)に一切依存させない
2. **条件付きLyapunovはまず数値摂動法**で実装(解析Jacobianは素子モデルごとに手計算が要るため後回し)。
   インターフェースは後から解析版を差し込める形にしておく
3. **ESP判定の閾値と窓は設定可能にし、既定値の根拠をdocs/design.mdに記録する**
   (判定基準を変えると結論が変わりうるため、感度も記録しておく)
4. 入力強度の定義を明示する(振幅か分散か)。実験2-Cの横軸の意味が曖昧にならないようにする

## 受け入れ条件

1. ρ<1 の条件で状態距離が指数的に減衰し、無入力・ρ>1 で減衰しないことを再現できる
2. **入力を強くすると ρ>1 でもESPが成立する条件が存在する**ことを、ヒートマップ上で示せる
   (通説の反例が図で見える状態)
3. 条件付きLyapunov指数の符号が、ESP判定(距離の収束/非収束)と整合する
4. リーク率と自己相関減衰の関係が単調に出る
5. washout長を変えたときの性能変動が定量化される
6. ESP判定関数が**ESN以外の状態系列(ダミーの外部生成系列)でも動く**ことをテストで確認
7. 図4枚が1コマンドで再生成 + pytest green

## 決定済み事項(2026-08-16サーベイ反映)

**課題パートの主張と出典が確定**(旧未確定4)。記事では**必要条件と十分条件を分けて**書く:

1. **十分条件ではない**: Yildiz, Jaeger & Kiebel (2012) "Re-visiting the echo state property",
   Neural Networks. 局所分岐解析により、ρ<1でもESPが失われる重み行列パターンの解析的反例を提示。
   あわせてsigmoid/leaky integrator ESNの新しい十分条件とESPの改良定義も与えている
2. **入力があれば必要条件でもない**: Scholarpedia "Echo state network"(Jaeger本人執筆)が
   「ESPをρ<1と同一視するのは広く流布した誤り。入力振幅が大きいほどρは1を超えて大きくてもESPが成立しうる」と明言
3. **無入力時には必要条件**: 無入力ならρ(W)<1がESPの必要条件(Woo et al., Complexity 2024 の整理)
   → 「無入力の議論を入力ありの設定に持ち込む誤用」が記事の骨子
4. **理論の現在地**(記事の締めに添える): Manjunath & Jaeger (2013) "Echo State Property Linked to an Input"
   (Neural Computation 25(3), 671–696)がESPを駆動入力の統計的性質に結びつけ、
   エルゴード入力に対する**0-1法則**を導出。従来定義は「入力の性質と結びついておらず実用上ほとんど役に立たない」と自ら指摘。
   さらにKobayashi, Tran & Nakajima (PRE 110, 024207, 2024)の非定常ESP・部分空間ESP、
   Woo et al. (2024)のノイズ駆動入力下のESP indexへ
