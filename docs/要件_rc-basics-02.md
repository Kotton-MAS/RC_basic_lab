# 要件: rc-basics-02 実験実装 —— ESN を動かして測る

*記事: `rc-basics-02`「ESNを動かして測る — ESP・スペクトル半径・リーク率」*
*前提: `rc-basics-01` の基盤が構築済み*

---

## 目的

記事02の小実験を実行可能にする。中心は **Echo State Property(ESP)の可視化と、
「スペクトル半径 < 1」という通説の検証**。

**移植目標**: ここで実装するESP判定は `memristor-rc-lab` の連載#2(不揮発素子でESPは成立するか)の
中核部品になる。リザバー実装に依存しない純関数として書くこと(01の設計判断1に準拠)。

## スコープ

### やること
- **ESP判定モジュール**(`diagnostics/esp.py`):
  - 2つの異なる初期状態から同一入力を流し、状態距離 `||x_a[t] − x_b[t]||` の時間発展を返す
  - 収束判定(閾値・判定窓は設定可能)
  - 条件付きLyapunov指数の数値推定(摂動法。**#3およびメモリスタ連載#3で再利用**)
- 実験2-A: **ESPを目で見る** —— ρを変えた複数条件で状態距離の減衰曲線を重ね描き
- 実験2-B: **リーク率は何を変えるのか** —— リーク率掃引に対する状態の自己相関減衰(実効時定数)の可視化
- 実験2-C(課題パートの実証): **入力駆動下では ρ>1 でもESPが成立しうる**ことの数値実演
  - 無入力・弱入力・強入力の3条件 × ρ格子でESP成立領域をヒートマップ化
  - **⚠️ 先行あり**: Gallicchio "Chasing the Echo State Property" が経験的ESP indexを導入して
    入力駆動下の安定領域を解析し「ESPの実際の妥当領域は文献条件よりずっと広い」と報告済み。
    本実験は**新規発見ではなく再実演**として位置づけ、記事で明示的に引用すること
- 実験2-D(課題パートの実証): **washout長への感度** —— washoutを変えて予測性能がどれだけ動くか

### やらないこと
- MC・IPCの測定(記事03)
- edge of chaos の性能相関(記事本文では論争の紹介に留め、検証は本編連載#3)
- ESP理論条件の解析的導出(記事は実測の可視化に徹する)

## 設計判断

1. **ESP判定は D-01 の共通署名 `f(X, u=None, y=None, *, ctx: DiagnosticContext | None) -> DiagnosticResult` に従う**
   (D-01 に合わせて更新: 旧`f(state_sequence_a, state_sequence_b) -> ESPResult`から変更)。
   比較対象の第2軌道は `ctx.companion_states` で渡し、位置引数を増やさない。
   リザバーの生成方法(ESN / メモリスタ回路)に一切依存させない(`X` / `ctx.companion_states` に
   渡す状態系列がどう生成されたかを問わない)
2. **条件付きLyapunovはまず数値摂動法**で実装(解析Jacobianは素子モデルごとに手計算が要るため後回し)。
   インターフェースは後から解析版を差し込める形にしておく
3. **ESP判定の閾値と窓は設定可能にし、既定値の根拠をdocs/design.mdに記録する**
   (判定基準を変えると結論が変わりうるため、感度も記録しておく)
4. 入力強度の定義を明示する(振幅か分散か)。実験2-Cの横軸の意味が曖昧にならないようにする

## 決定済み事項(2026-08-16サーベイ反映)

**課題パートの主張と出典が確定**(旧未確定4)。記事では**必要条件と十分条件を分けて**書く:

1. **十分条件ではない**: Yildiz, Jaeger & Kiebel (2012) "Re-visiting the echo state property",
   Neural Networks. 局所分岐解析により、ρ<1でもESPが失われる重み行列パターンの解析的反例を提示。
   あわせてsigmoid/leaky integrator ESNの新しい十分条件とESPの改良定義も与えている
2. **入力があれば必要条件でもない**: Scholarpedia "Echo state network"(Jaeger本人執筆)が
   「ESPをρ<1と同一視するのは広く流布した誤り。入力振幅が大きいほどρは1を超えて大きくてもESPが成立しうる」と明言
3. **無入力時には必要条件**: 無入力ならρ(W)<1がESPの必要条件(Woo et al., Complexity 2024 の整理)
   → 「無入力の議論を入力ありの設定に持ち込む誤用」が記事の骨子
4. **理論の現在地**(記事の締めに添える): Manjunath & Jaeger (2013) "Echo State Property Linked to an Input"
   (Neural Computation 25(3), 671–696)がESPを駆動入力の統計的性質に結びつけ、
   エルゴード入力に対する**0-1法則**を導出。従来定義は「入力の性質と結びついておらず実用上ほとんど役に立たない」と自ら指摘。
   さらにKobayashi, Tran & Nakajima (PRE 110, 024207, 2024)の非定常ESP・部分空間ESP、
   Woo et al. (2024)のノイズ駆動入力下のESP indexへ

## 未確定事項(質問リスト・重要度順)

1. **[決定済み]** ESP判定の収束閾値と判定窓の既定値(まず暫定値で回し、感度を見て確定)
   → **距離は RMS/ユニット `||x_a - x_b|| / sqrt(N)`、判定は
   「末尾 `window` ステップの中央値 <= max(`abs_tol`, `rel_tol` * `d_initial`)」。
   既定 `abs_tol=1e-6` / `rel_tol=1e-3` / `window=200`**(D-16)。
   `sqrt(N)` 正規化は閾値を N に依存させないため(N の異なる系へ移植できる)。
   `abs_tol=1e-6` は float64 の eps から10桁上で、初期距離 O(1) から6桁の収縮を要求する。
   **感度を実測して確定した**: `abs_tol` 3点 x `window` 3点の9通りで 2-C の格子
   (336条件)を判定し直したところ、**σ_u 別の臨界 ρ は1点も動かない**
   (判定が変わったのは `window=400` の1条件のみ)。収束側の `d_tail` が 1e-16 台、
   非収束側が 0.1〜1 台で**4桁以上の空白がある**ためである。
   一次資料 `results/02_esp_and_dynamics/esp_threshold_sensitivity.csv`(9行) /
   根拠 `docs/design.md` §9.1〜9.2 / 再生成 `make threshold-02`

2. **[決定済み]** 条件付きLyapunov指数の摂動サイズと再正規化間隔
   → **摂動法、`delta=1e-8`(RMS/ユニット)、再正規化間隔 1 ステップ、
   `method='perturbation'` 以外は `ValueError`**(D-18)。
   `delta` は非線形項 `O(delta^2)` と丸め誤差 `O(eps/delta)` が釣り合う
   `sqrt(eps)=1.49e-8` 近傍の古典的な最適点。間隔1は摂動が線形域を外れない最も安全な
   選択で、線形写像 `x -> A x` に対する推定値が `log ρ` と**相対誤差 1e-9 台**で一致する。
   線形域の内側にいることの実測: 本番格子 336条件の `max_observed_growth` は
   最大 **1.5372**(中央値 1.0873)で、暴走検出の上限 `max_growth=1000` に対して 650 倍の余裕。
   あわせて **伝播器 `propagator(X[t], t) == X[t+1]` の整合を実行時に検査する**
   (`check_propagator` 既定 true)。`u[t+1]` を `u[t]` に取り違えると λ が -0.02 から
   +15〜+17 へ跳ねるが、検査が無ければ「それらしい値」として通ってしまう。
   根拠 `docs/design.md` §9.3

3. **[決定済み]** 初期状態のばらつかせ方(一様乱数 / 片方をゼロ状態にする、など)
   → **`U[-1,1]^N` から `n_pairs + 1` 本を独立に引く。片方をゼロ状態にしない。
   本数の既定は 10**(D-16 / D-21)。
   ゼロ状態にしないのは、無入力ではゼロが不動点なので「2軌道の分離」ではなく
   「単一軌道の原点への収束」を測ることになり ESP と別の量に化けるため。
   本数を 3 から 10 に上げたのは、無入力・ρ>1 の tanh リザバーが `+x*` / `-x*` の対を
   なす吸引子を持ち、比較軌道が k 本すべて参照軌道と同じ側へ落ちる確率が約 `2^-k`
   残るため。**`n_pairs=3` では偽陽性確率が `2^-3` あり、実測で特定の draw が
   ρ=1.05〜1.5・無入力を「収束」と誤判定した**(受け入れ条件1 が不成立になった)。
   初期状態は4本目の乱数ストリーム `SeedStream.PROBE` から引き、リザバー重み・駆動信号と
   独立に振れるようにしてある(D-14)。根拠 `docs/design.md` §9.4

4. **[記事執筆時のサーベイ課題として残す]** Gallicchio のESP indexの定義と、
   本要件のESP判定(2初期値の距離収束)との対応関係を確認する
   → 仕様 §8 の前提どおり**実装スコープ外**。本サイクルでは 2初期値の距離収束
   (D-16)と条件付き Lyapunov 指数(D-18)の2本立てで測り切っており、ESP index との
   定義の対応精査は文献調査であって実装判断ではない。記事の「理論の現在地」節
   (Manjunath & Jaeger 2013 / Woo et al. 2024)を書く段で扱う

5. **[決定済み]** washout感度実験のタスク選定(01のどのタスクを使うか)
   → **01 の2課題(Mackey-Glass と遅延パリティ)を両方、3手法すべてで回す。
   図と `meta.json` の主役は MG x ESN に固定**(`HEADLINE_TASK` / `HEADLINE_METHOD`)。
   実体は `washout` だけ差し替えて既存の `run_experiment` を呼ぶループなので、
   公平性(D-04 / D-05 / D-08)は既存経路が担保する。
   あわせて **washout と訓練データ量の交絡を除く補償を既定にした**(D-19)。
   当初の予測「遅延パリティは washout に反応しない対照になる」は
   **データで支持されなかった**: 補償後は6組すべてで変動幅がレプリケート間の
   ばらつきの内側(`exceeds_replicate_noise = false`)で、**どちらの課題も反応しない**。
   補償を外すと MG x ESN の NRMSE は washout に対して完全に単調増加(比 1.0115)するが、
   それは訓練データ量の効果だった。根拠 `docs/design.md` §9.6
