# 要件: rc-basics-04 実験実装 —— カオス時系列を自走させる

*記事: `rc-basics-04`「リザバーが本当に強い場所 — カオス時系列の自由走行予測」*
*前提: `rc-basics-01`〜`03` の基盤が構築済み*

---

## 目的

記事04の実験を実行可能にする。中心は **自由走行(closed-loop)によるカオスアトラクタの再現**。

連載でここまで積み上げた「リザバーは遅延線に勝てるのか」という問いに対し、
**初めてリザバーが明確に勝つ場面**を提示する回。ただし勝ちを主張するために、
これまでと同じ厳密さで対照を置く。

**位置づけ**: 1ステップ先予測(教師強制)ではなく自走を主役にする。理由は
(a) 1ステップ先予測は遅延線・persistenceと差がつきにくく、連載が批判してきた構図そのもの
(b) 自走は「力学系そのものを学習しているか」を問う質的に別の課題であり、
    出力を入力に戻す構造上、記憶を持たない対照には原理的に真似できない

## スコープ

### やること
- **カオス系の生成器**(`tasks/chaotic.py`): Lorenz系(連続時間・RK4で積分後にサンプリング)と
  Mackey-Glass(τ=17、離散化)の2種。`docs/design.md`に積分法・刻み幅・サンプリング間隔を記録
- **自由走行モード**(`readout/autoregressive.py`): 学習済みread-outの出力を次時刻の入力に戻す実行系。
  ウォームアップ(教師強制)→自走への切り替え点を設定可能にする
- 実験4-A: **教師強制での1ステップ先予測** —— ESN / 遅延線 / persistence の3対照で比較。
  ここでは差が小さいことを確認する(連載の問題意識の再確認)
- 実験4-B(**記事の目玉**): **自由走行** —— ウォームアップ後に自走させ、
  (i) 軌道の可視化(Lorenzは3D位相図、Mackey-Glassは遅延座標埋め込み)
  (ii) 有効予測時間(真の軌道との誤差が閾値を超えるまでの時間、Lyapunov時間で正規化)
  (iii) **長時間走らせた後の統計量の再現**(アトラクタの形、リターンマップ、パワースペクトル)
- 実験4-C: 自走の安定性がハイパーパラメータ(ρ、リーク率、ノイズ注入量、正則化)にどう依存するか。
  発散・周期軌道への落ち込み・アトラクタ再現の3態を分類してマップ化
- 実験4-D(課題パート): **自走性能とMC/IPCの関係** —— 03で実装した診断を当て、
  自走が上手くいく領域が容量指標で説明できるかを見る

### やらないこと
- ハイブリッド手法(物理モデル+RC)、Next-Generation RC(NVAR)との比較(触れるに留める)
- 高次元カオス(Kuramoto-Sivashinsky等)への拡張。v0.1は低次元系に絞る
- 実データのカオス時系列(記事05で実データを扱う)

## 設計判断

1. **自由走行の評価は「短期予測精度」と「長期統計量」を分けて報告する**。
   カオス系は原理的に長期予測不能なので、有効予測時間は**Lyapunov時間で正規化**して報告する
   (「何ステップ当たったか」ではなく「何Lyapunov時間もったか」)。生の時間軸だけで語らない
2. **対照は persistence と遅延線の両方を置く**。ただし自走では両者が原理的に不利であることを
   記事で明示する(公平な比較ではなく、**課題の性質が変わったこと**を示すための対照)
3. **ノイズ注入を実装しておく**。自走の安定化には学習時の状態へのノイズ付加が効くことが知られており、
   これを入れずに「自走が不安定」と結論すると誤り。実験4-Cの軸に含める
4. アトラクタ再現の定量化は視覚評価に頼らず、**リターンマップの分布距離**または
   **パワースペクトルの一致度**で数値化する(「絵が似ている」で終わらせない)

## 入力 / 出力

- **入力**: 実験設定YAML(カオス系の種別・パラメータ・積分設定 / リザバー設定 /
  ウォームアップ長 / 自走長 / ノイズ注入量 / 対照手法 / シード)
- **出力**:
  - `results/fig_onestep.png`: 教師強制での3手法比較(差が小さいことを示す)
  - `results/fig_freerun_attractor.png`: **自走軌道と真の軌道の位相図の重ね描き(記事の主図)**
  - `results/fig_valid_time.png`: 有効予測時間(Lyapunov時間で正規化)のシード分布
  - `results/fig_stability_map.png`: ρ×リーク率(×ノイズ)に対する自走の3態分類マップ
  - `results/fig_freerun_stats.png`: 長時間自走後のリターンマップ/パワースペクトル比較
  - `results/freerun.csv`, `results/meta.json`

## 制約

- 既存基盤(01〜03)を再利用。新規依存は増やさない(numpy, scipy, matplotlib, pyyaml)
- 全実験がCPUで完走すること(自走は逐次計算なのでベクトル化に注意)
- Lorenzの最大Lyapunov指数は既知値を用いてよいが、**出典または数値推定の方法を記録する**
- Apache-2.0 / 個人名義

## 受け入れ条件

1. Lorenz系で、ウォームアップ後の自走軌道が**蝶形アトラクタを再現する**図が出る
2. 有効予測時間が**Lyapunov時間で正規化**して報告され、シード10本以上の分布が出る
3. 教師強制の1ステップ先予測では ESN と遅延線の差が小さいこと、
   自走では対照が成立しないことの両方が数値で示される
4. 自走の3態(発散/周期軌道/アトラクタ再現)がハイパーパラメータ平面で分類され、
   ノイズ注入の有無で領域が変わることを確認できる
5. 長時間自走後の統計量(リターンマップまたはパワースペクトル)が真の系と定量比較されている
6. 図5枚が1コマンドで再生成 + pytest green
7. 自走モジュールが**外部生成の状態系列生成器でも動く**(移植性の担保。メモリスタ本編で再利用)

## 未確定事項

1. Lorenzのサンプリング間隔Δt(小さすぎると自明な予測になり、大きすぎると学習困難)
2. 有効予測時間の誤差閾値(RMSE比で0.3〜0.4程度が慣例だが要確認)
3. ノイズ注入の方式(状態に加算 / 入力に加算)と大きさの格子
4. Mackey-Glassを含めるか、Lorenzのみに絞るか **(仮: Lorenz主・MG従)**
5. 記事でNext-Generation RC(NVAR)に触れる際の記述範囲(比較実装まではしない)
