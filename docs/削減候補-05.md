## 3.5 合否判定の射程 (実測で判明した限界。**着手前に必ず読む**)

D-74 の指紋検査は **「コミット済みの成果物が編集されていないこと」** を測る。
**「再生成しても同じバイト列になること」は測っていない。**
成果物を生成する層 (plotting / CSV 書き出し) を触るときは、この差が効く。

実測 (実験01を一時ディレクトリへ再生成し、コミット済みと比較):

| 種別 | 再生成でバイト一致するか | 理由 |
|---|---|---|
| **PNG** | **する** (`fig_comparison.png` / `fig_state_space.png` とも指紋と完全一致) | matplotlib の出力はこの環境では再現的 |
| **CSV** | **しない** | 最終列が `wall_time_s` で実行ごとに変わる。**それ以外の列は完全一致** |

したがって:

- **plotting を触る変更は「再生成して指紋と一致するか」で検証できる。**
  実際、#8 (plotting の共通化) はこの方法で振る舞い不変を実証した
- **CSV 書き出しを触る変更 (#4) はそれができない。**
  `wall_time_s` 列を除いた比較が受け入れ条件になる。
  「再生成したら差分が出た」を理由に指紋を書き直してはいけない ——
  それは合否判定そのものを無効にする

再生成の例 (`results/` を汚さない):

```
uv run python experiments/01_what_is_rc/run.py \
  --config experiments/01_what_is_rc/config.yaml --out <一時ディレクトリ>
```

## 3.6 整理の過程で見つかった成果物の乖離 (解消済み) と、そこから見えた問題

### 何が起きていたか

`write_*_csv` の共通化 (#4) を検証する過程で、
**コミット済みの `results/02_esp_and_dynamics/meta.json` が現行コードの出力と食い違っていた**
ことが分かった。

- 差分は `washout_sensitivity.sizes_by_washout` / `t0_by_washout` の
  **`task` フィールドの有無**だけ (コミット済みは無し・6件、コードの出力は有り・12件)
- 時間系を除いた 135 葉のうち、**食い違いはこの2つだけ**。科学的な数値は完全に一致

**原因**: `washout.py` の最終変更は 2026-08-18、コミット済み `meta.json` の最終更新は 2026-08-19 で、
そのコミットのタイトルは **「revert: results/ を T1 着手前の状態へ戻す」**。
つまり `results/` を意図的に巻き戻した際に、コードには残った `task` フィールドと乖離した。

**なぜ気づかれなかったか**: この系のガードは「成果物を編集していないこと」しか測っておらず、
**「再生成したらコードの出力と一致するか」を測る仕組みが無かった**。
D-74 の指紋はこの乖離した状態をそのまま固定していた。

### 対応 (実施済み)

`make figures-02` で再生成し、指紋を更新した。

- **図4枚はバイト不変** (再生成しても変わらなかった)
- CSV 2本は `wall_time` 列を除いて**完全一致** (369行 / 180行)。科学的な数値は動いていない
- `meta.json` は `task` フィールドが入り、コードの出力と一致するようになった

### そこから見えた問題 (次のPR候補)

**`README.md` が機械依存の数値を機械照合の対象にしている。**

再生成で `tests/test_readme_summary.py::test_readme_experiment_02_numbers_match_meta_json` が
`assert 87.69 == 88.0` で落ちた。中身は `wall_time_s` —— 実行環境で変わる値である。

README 77行目の `(実測 wall_time_s = 87.69 秒)` を 88.0 に更新して緑に戻したが、
**この検査は誰がどのマシンで再生成しても落ちる**。科学的な数値の照合は価値があるが、
`wall_time_s` を厳密一致で縛るのは、再生成のたびに README を書き換える義務を生むだけである。

対応案: `wall_time_s` を照合対象から外すか、桁を落とす (例: 「約90秒」) か、許容幅を持たせる。
