# 仕様と指示の置き場

`docs/plans/` には2種類ある。

| 種類 | 寿命 | 例 |
|---|---|---|
| **サイクルの仕様書** (`rc-basics-0N.md`) | **恒久**。コードが `仕様 §5` の形で約 170 箇所から参照する | `rc-basics-03.md` |
| **一時的な指示書・レビュー** | **消化したら畳む**。中身は決定 (`.claude/decisions/`) とコードへ移る | 下の表 |

一時的な指示書を残し続けると、**同じ判断が指示書と決定とコードの3箇所に散る**
(CLAUDE.md「散文が3箇所にあると3箇所が独立にドリフトする」)。消化した時点で
本体を消し、**何を指示され・何を生んだか**の1行だけをここに残す。
中身が要るときは `git log --follow -- <パス>` で読める。
