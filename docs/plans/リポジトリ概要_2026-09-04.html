1. これは何か

4. 差し替えられる部品

YAML の kind で選べるもの。足すときは union に 1 行 + case を 1 つ

リザバー reservoir/

esn
Echo State Network（Jaeger 2001）。既定。ランダム疎結合 + 漏れ積分 tanh
deep_esn
層を積む（Gallicchio & Micheli 2017）。層間の辺も adjacency() に含める
ring
単一閉路 + 大きさ一定の入力重み（SCR、Rodan & Tino 2011）。乱数をほとんど使わない

面は config / n_units / n_inputs / step / run の 5 つだけ。結合行列を持つモデルだけが追加で GraphReservoir（adjacency()）を満たします。

トポロジ reservoir/topology.py

結合の有無をモデル本体から切り離した軸。更新式を固定して形だけを振れます。

erdos_renyi
一様ランダム。既定（density 0.1）。自己ループあり、非対称
barabasi_albert
優先的選択によるスケールフリー。対称・自己ループなし
watts_strogatz
スモールワールド（k, β）。対称・自己ループなし
ring
一方向の閉路。乱数を消費しない
degree_preserving
土台のグラフの次数列を保って辺を張り替える帰無モデル（D-135）
control
対称化だけ／自己ループ除去だけ、という交絡を 1 つだけ動かす対照（D-138）

重みは値を先に引いてからマスクで切り出す順（D-134）なので、同じシードで ER と BA を作ると重みが一致し、対応のある比較が組めます。

6. これまでに分かったこと

数値は results/ の実測。記事 02〜05 の既存の数値とは全一致を確認済み

01 リザバーは何を足しているか

Mackey-Glass 1 ステップ先では遅延線と ESN が同じ桁（NRMSE 0.0005 / 0.0007）。遅延パリティはESN だけが解ける（0.089 対 1.00）。目標が遅延線の線形空間に厳密に直交するため。

02 ESP

無入力なら ρ < 1 が必要条件だが、入力を強くすると境界が動く（σ_u = 1.0 で境界 ρ = 1.7、2.0 で格子内に境界なし）。washout は訓練長を補償すると効かない（6 組すべて変動比 1.008 以内）。λ < 0 なのに非収束が 27/332（8.1%）— 原因は多安定性で、λ は ESP の代わりにならない。

03 容量と NARMA10

  • MC は ρ = 1 付近で最大だが上限 N の 2 割弱（18.9%）。残りは非線形に回っている
  • ρ を上げると非線形容量が 22.2 → 4.6 と 5 分の 1 に落ちる。上げすぎると線形も減る
  • NARMA10（N=50, leak 0.3）は遅延線 0.1538 が ESN 0.2673 を上回る。ESN は容量の 2/3 を課題が要求していない非線形に使っていた
  • 3-C'': 動作点を動かすと勝敗が変わる。N=200/leak 1.0 で 0.0514、N=100/leak 1.0 で 0.1037 —— どちらも遅延線を下回る
  • 3-T: 密度をそろえると BA は ER を上回らない（対応のある差 −1.92、正の対 2/24、N とともに差が開く）。BA − 次数保存ランダム化 = +0.13（15/24）で、BA の効果は次数列だけで説明が付く。しきい値 10 通りで差は −2.52〜−2.55

04 カオスの自走

1 ステップ先では差が出ないのに、自走では ESN 4.73 Lyapunov 時間 対 遅延線 0.25（19 倍）。遅延線の自走は 10 本とも周期軌道に落ちる。ESN の自走は位相がずれてもアトラクタの形と統計を保つ（シャッフル代替より 10/10 近い、p = 0.00098）。状態ノイズを 4 桁振っても再現できる領域はほとんど動かない。

05 異常検知（MGAB）

6 系統のうち一様乱数対照を超えたのは ESN 残差だけ（AUPRC 0.160 対 0.057、15 対中 15 対）。プロトコルを 27 通り変えても ESN の首位は動かず、順位が入れ替わるのは対照と区別できない集団の中だけ。

7. 品質を守る仕組み

散文ではなく機械で守っているもの

成果物のバイト不変
リファクタリングの唯一の合否判定（D-74）。test_artifact_invariance がバイト指紋と内容指紋（実行時間を除く）を別々に照合
golden
縮小設定で再生成した成果物の不変を数秒で検査。プラットフォーム固定（macOS）
決定の記録
decisions.yaml の各件が guard_test を持ち、変異注入で赤くなることを確認してから記録。ID の一意性・キー重複・参照解決を検査
行数のラチェット
1 モジュール 600 行。超過中の 7 本は現在値で凍結（増えたら落ちる、減らすのは自由）
層の境界
import を実測して逆流 0 件を検査。diagnostics は reservoir を知らない
core / series
汎用側だけを一時ディレクトリへ複製し、連載側なしで実験を 1 本回す（test_core_extraction）
図の規約
アスペクト比 ≤ 2.3、凡例は軸内、参照線に出典、footnote に条件と commit（FIG-1〜16）
診断の署名
pkgutil で全診断を列挙し、X 族と W 族が交わらないこと・追加引数の境界を検査
時間予算
test_wall_time_budgets が各実験の実測を budget_s と照合

make ci（lock-check + ruff + mypy strict + pytest）が Stop hook と GitHub Actions の両方から呼ばれ、ローカルと CI の判定を 1 本にしています。
